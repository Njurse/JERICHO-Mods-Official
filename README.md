# JERICHO Mods Official

Official catalog of modules for [JERICHO](https://github.com/Njurse/JERICHO).

This repository does **not** contain the mod source. It is a curated index that references the modules living in the main JERICHO tree (or their own repositories). Drop the listed folders into your game’s `JERICHO/MODS/` after building or cloning the source.

## Install

1. Build or obtain the modules from the main [JERICHO](https://github.com/Njurse/JERICHO) repository (they live under `JERICHO/MODS/<id>/`).
2. Copy each desired folder into your install’s `JERICHO/MODS/`.
3. Enable them under **Options → JERICHO**.

See `mods.json` for the current official list and `docs/STRUCTURE.md` for the expected folder layout.
